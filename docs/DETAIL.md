# 网课整理器 / Course matrix

给一个学科或课程名，自动在 B 站搜索公开网课，验证候选课程的完整分P与时长，再整理成能直接打开的表格。

## 它解决什么

找网课最费时间的不是“搜”，而是**判断**：这条视频是完整课还是试听切片？144 集还是 5 集？作者是不是在卖课？本插件把“搜—验—排表”三步固化成三个工具，模型只需要做取舍判断。

## 三个工具

### `bili_search`

按关键词搜索公开视频，返回排序后的候选：标题、UP 主、播放量、时长、BV 号、链接。

- `keyword`（必填）：学科或课程名，如 `管理学基础`、`微观经济学`、`考研政治`
- `limit`：返回条数，1–50
- `order`：`totalrank` 综合（默认）/ `click` 播放最多 / `pubdate` 最新 / `dm` 弹幕最多

### `bili_course`

给一个 BV 号，返回完整元数据与分P清单。

- `bvid`（必填）：如 `BV1wZ421M76J`
- `max_pages`：最多返回多少个分P（默认 60；`pageCount` 始终是真实总数）

返回值里 `likelyFunnel` 为 `true` 时，表示标题、简介或分P名里出现“完整版+微信”“私信”“引流”等字样——**大概率是卖课的试听切片，不是免费全集**。

### `course_matrix_xlsx`

把整理结果写成带样式的 `.xlsx`，零依赖，不需要装 Excel，也不需要 npm 包。

- `output`（必填）：目标路径，父目录会自动创建
- `sheets`（必填）：一个或多个表，每表支持
  - `name` 表名
  - `widths` 列宽数组
  - `freeze` 冻结窗格，如 `{ row: 1, col: 2 }`
  - `autoFilter` 表头筛选
  - `rows` 行数据，单元格为字符串/数字，或 `{ value, style }`

可用样式：`header`（深蓝底白字）、`bold`、`center`、`gray`、`plain`（无边框）、`default`。

## 典型流程

1. 用 1–3 个关键词变体 `bili_search`，例如“管理学”“管理学基础 专升本”“管理学 马工程 全套”
2. 对前 5–8 个候选逐个 `bili_course`，看三件事：**分P数**、**总时长**、**是否 likelyFunnel**
3. 按“完整免费 > 长且免费 > 付费/切片”排序，保留理由写进备注
4. `course_matrix_xlsx` 出一张总表：课程清单 + 分P明细（可选第二表）
5. 在回复里给出推荐顺序与避坑说明

## 限制（务必如实告知使用者）

- **只读公开数据**：不登录、不购买、不下载视频或课件
- B 站搜索接口有频率限制，短时间内大量请求可能返回 `-412`，等一会儿再试
- 搜索结果里的时长是视频总长，不等于“有效学习内容”长度
- `course_matrix_xlsx` 不支持公式、图表、下拉数据验证、条件格式
- 判断“课程是否对口某场考试”仍需要模型结合考纲完成，本插件只负责网课的搜集与核验
