# 网课整理器 · dsh-course-matrix

给一个学科名，或者直接粘一份考纲，自动去 B 站找公开网课、核实真假完整、整理成能直接用的表格。

DSH 插件（bundle），包含侧边栏面板、三个工具和一个技能。

## 它解决什么

找网课最费时间的不是搜，是**判断**：

- 这条视频是完整课，还是 3 集的试听切片？
- 标题写着「第 5 版精讲」，实际内容对不对？
- 作者是不是在引流卖课（分P名里藏「完整版➕薇」）？
- 这门课讲的那一节，到底在第几集第几分钟？

插件把这些判断固化下来，并给出可直接跳转的位置。

## 两个入口

### 按学科搜

输入课程名 + 学段（小学/初中/高中/大学期末/专升本/考研/考公考编/职业资格/兴趣自学），得到按匹配度排序的网课清单。

筛选条件：

| 检查项 | 处理 |
|---|---|
| 分P数 ≤ 3 | 判为试听切片，剔除 |
| 分P名称大量重复 | 扣分 |
| 平均每集 < 3 分钟 | 扣分 |
| 分P名含引流联系方式 | 扣分并标记 |
| 标题与搜索词只蹭上一个两字词 | 判为不相关，剔除 |

还可以额外搜「全网资料」（课件、PPT、出版社资源站），走宿主提供的网页搜索。

### 按考纲整理

粘贴考纲文本（支持 `1` / `（1）` / `第一章` / `一、` / `必修一` 各种编号），加上科目名，得到**每条考纲 → 对应网课分P**的对照表：

```
【管理基础知识】了解组织环境…PEST/SWOT/五力
   [主] P32  17h00m  组织内外部环境要素及其分析方法  之了144P
   [主] P28  12h39m  计划编制的环境分析（一）        2026版92P
   [补] P1   0m      经管基础考纲分析及导学         福建16P
```

- `[主]` 集数够、能撑起整章的全科课
- `[补]` 只讲到部分内容的课，作参考
- `P32` 分P序号，`17h00m` 是该集在整门课里的起点，直接拖进度条
- 每条最多 5 个参考位置，每门课最多占 2 个

结果可一键导出 `.xlsx`（两个 Sheet：考纲对照 / 课程清单）。

## 三个工具（给 agent 用）

| 工具 | 作用 |
|---|---|
| `bili_search` | 按关键词搜 B 站公开视频 |
| `bili_course` | 读一个 BV 号的完整分P清单，并标记疑似引流 |
| `course_matrix_xlsx` | 写带样式/冻结/筛选的 `.xlsx`，零依赖 |

## 安装

### 从本地目录

**插件** → **添加插件** → 选择本目录。

或命令行：

```sh
dsh plugin install ./course-matrix
```

## 配置

`cordis.patch.yml` 里可改：

```yaml
- insert:
    - id: course-matrix
      name: 'dsh-course-matrix'
      config:
        defaultSearchLimit: 15   # bili_search 默认返回条数
```

## 限制

- **只读公开数据**：不登录、不下载视频、不购买课程
- B 站接口有频率限制，短时间大量请求会返回 `412`，稍等再试
- 考纲对照是**词面匹配**，不是语义理解。同义改写（考纲说「边际报酬递减规律」、分P叫「短期生产函数」）会匹配不上；泛词（「理论」「分析」）可能误配。表里给了匹配分，低分项需人工核对
- `course_matrix_xlsx` 不支持公式、图表、下拉数据验证、条件格式
- 全网资料检索依赖宿主的网页搜索服务；未配置时该功能不可用
